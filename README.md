# Anuoluwapo Maternity Hospital Website

A responsive maternity hospital website built with HTML, CSS, and JavaScript.

## Project Overview

Anuoluwapo Maternity Hospital is a front-end website concept designed to provide visitors with information about hospital services and make it easy to navigate important hospital pages.

The project focuses on creating a clean, responsive, and user-friendly hospital website.

## Features

- Responsive homepage
- Hospital introduction section
- Hospital services section
- Why Choose Us section
- Login page
- Sign-up page
- Forgot-password page
- Appointment page
- About Us page
- Contact page
- Navigation between pages
- Mobile navigation menu
- Basic form interaction
- Responsive design for mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub
